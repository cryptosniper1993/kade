# Projectbeheer

Twee schermen: **Taken** en **Projecten**.

## Taken

**Doel:** één lijst van wat moet gebeuren, met een eigenaar. Naast gewone taken (**Todo**) bestaan **CIP**-punten (continue verbetering: iets wat fout liep of blijft terugkomen).

### Stap voor stap

1. Kies bovenaan het formulier **Todo** of **CIP**.
2. Vul **Taak** (bij CIP: **Maatregel**) in, en de overige velden.
3. Druk **Zet op de lijst** (melding "Taak staat erop." / "CIP staat erop.").
4. Filter de lijst met **Open / Prio / CIP / Klaar / Alles**.
5. Zet per taak de status op **Open / Bezig / Klaar**, wijs toe of verwijder.
6. Voeg personen toe onder **Personen** (naam en rol) met **Persoon toevoegen**.

### Alle opties

| Plaats | Veld / knop | Opties |
| --- | --- | --- |
| Nieuwe taak / Nieuw CIP | Soort | **Todo**, **CIP** |
| | Taak / Maatregel | vrije tekst |
| | Aanleiding (CIP) | "Wat liep fout, of wat blijft terugkomen" |
| | Persoon | **Niet toegewezen** of een persoon |
| | Project | **Los van een project** of een project |
| | Prio | **Hoog**, **Normaal**, **Laag** |
| | Deadline | datum |
| | Notitie | optioneel |
| | Knop | **Zet op de lijst** |
| Personen | Naam, Rol (bv. stuurman, dev, boekhouding) | **Persoon toevoegen**; per persoon **Zet uit** / **Zet aan** |
| Filter | | **Open**, **Prio**, **CIP**, **Klaar**, **Alles** |
| Per taak | Status | **Open**, **Bezig**, **Klaar** |
| | Toewijzen | **Niet toegewezen** of een persoon |
| | Verwijderen | knop (melding "Taak weg.") |

## Projecten

**Doel:** één takenlijst per project, met status en deadline. Offertes, inventaris en storingen kunnen aan een project hangen.

### Stap voor stap

1. Vul **Project** (naam), optioneel **Voor wie** (klant of intern), **Deadline**/**Streefdatum**, en druk **Project openen**.
2. Klik een project in de lijst om het te openen.
3. Zet de status op **Actief / Pauze / Klaar**.
4. Voeg taken toe in **Todo van dit project** (soort Todo of CIP, persoon, prio, deadline, notitie) met **Toevoegen**.
5. Afgewerkte taken staan onder **Al klaar**.

### Alle opties

| Plaats | Veld / knop | Opties |
| --- | --- | --- |
| Nieuw project | Project, Voor wie, Streefdatum/Deadline | **Project openen** |
| Projectkaart | Status | **Actief**, **Pauze**, **Klaar** |
| Todo van dit project | Soort | **Todo**, **CIP** |
| | Taak / CIP-maatregel | vrije tekst |
| | Persoon | **Niet toegewezen** of een persoon |
| | Prio | **Hoog**, **Normaal**, **Laag** |
| | Deadline, Notitie | optioneel |
| | Knop | **Toevoegen** |
| Per taak | Status, Toewijzen, verwijderen | zoals bij Taken |
