# Handleiding KADE zaakterminal

KADE is de zaakterminal voor een Belgische IT-zaak (btw-nummer, ook in bijberoep). Bovenaan kies je een **hoofdonderdeel**; links (of op gsm bovenaan) kies je het scherm binnen dat onderdeel. Met **Zoek ⌘K** (Ctrl+K op Windows) spring je direct naar elk scherm. Het adres onthoudt het scherm (bv. `#facturen`), zodat je kan bladwijzeren.

| Hoofdonderdeel | Schermen | Handleiding |
| --- | --- | --- |
| Brug | Brug (dagoverzicht) | [brug.md](brug.md) |
| Projectbeheer | Taken, Projecten | [projectbeheer.md](projectbeheer.md) |
| Finance | Klanten, Leveranciers, Offertes, Facturen, Inkomend, Boeken, Balans, Inventaris, Analyse, Schaar, Archief | [finance.md](finance.md) |
| Agents | Hoofd, Loots, Research, Bots, Logboek, Post | [agents.md](agents.md) |
| Beheer | Zaak, Instellingen (Hoofdstem, Peppol, Grok Bot) | [beheer.md](beheer.md) |

Extra:

- [peppol-provider.md](peppol-provider.md) — een Peppol access point kiezen en koppelen, versturen én ontvangen testen.

Algemeen:

- Meldingen verschijnen rechtsonder en verdwijnen na enkele seconden.
- **Afmelden** staat rechtsboven (alleen als aanmelden aan staat).
- In de demo (account `demo@noorderlicht.example`) staat bovenaan een banner; de cijfers zijn een voorbeeld.
